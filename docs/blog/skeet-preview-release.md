# トラップ専用だったShoot Logに、スキートの入口を作りました

Shoot Logは、これまでトラップ専用のアプリだった。

自分がトラップ銃しか持っていないのだから、これは当然といえば当然だ。実際に射撃場で使いながら、「ここは押しにくい」「この記録も残したい」と直してきた。だから今の形になった。

ところが、ここまで作ると欲が出る。

トラップで使えるなら、スキートでも使えるのではないか。

問題は、私がスキートを撃ったことがないことだ。

## 知らないまま作るのは危ない

トラップの入力画面を名前だけ変えて使い回すことはできない。

スキートには8つの射台があり、ハイハウスとローハウス、シングルとダブルがある。射順もトラップとはまったく違う。

そこでVersion 2.22では、ISSF資格射撃の25枚順を基にした「Skeet Preview」を追加した。

- 8射台
- High／Low
- Single／Double
- ダブルで撃つ順番
- 命中／失中の入力
- 射台別、High／Low別の基本集計

ここまではアプリに入れた。

ただし、完成版とは呼ばない。

ルールとして正しくても、射撃中に使いやすいとは限らないからだ。

## スキート射手の方に聞きたいこと

実際にスキートを撃つ方に、次の点を見ていただきたい。

1. 25枚の並びとHigh／Low、ダブル順の表示は分かりやすいか
2. 射撃中に「命中／失中」を入力する操作は現実的か
3. 画面に必ず表示してほしい情報は何か
4. 振り返りや分析で、射台以外に何を比較したいか
5. 射撃場や練習方法によって別の入力順が必要か

私はスキートの経験がない。だから想像で完成させるより、実際に撃つ方の意見を受けて直したい。

「ここが違う」「この順番では使いにくい」という指摘ほどありがたい。

## 日本語と英語を切り替えられます

Shoot Logは日本語と英語の表示に対応している。

「アカウント設定」の「表示言語」から、Japanese／Englishを切り替えられる。選択は端末ごとに保存され、射撃記録の内容には影響しない。

英語表示に切り替えると、履歴、入力、分析、実包管理、所持許可、バックアップ、問い合わせ、操作マニュアルまで英語になる。

海外の射手にも画面を見てもらいやすくなった。スキート試作版への意見も、日本語・英語のどちらでも歓迎したい。

## トラップとスキートの履歴も見分けやすく

同じ履歴にTrapとSkeetが並んでも判別しやすいよう、カードの背景色をわずかに変えた。

派手に色分けすると記録が読みにくくなるので、Skeetだけを淡い紫にしている。種目名もカード内に表示されるため、色だけに頼らず確認できる。

## まずは入口から

トラップ版も、最初から今の形だったわけではない。

射撃場で使い、気づいたところを直し、「二発目を撃ってしまった」という記録まで増えていった。

スキートも同じように育てたい。

私は撃たない。だから、撃つ人に教えてもらう。

アプリを作った本人が一番ルールを知らないという、少々妙なスタートではある。でも、知らないものを勝手に分かったことにしないのも、ものづくりでは大事だと思う。
